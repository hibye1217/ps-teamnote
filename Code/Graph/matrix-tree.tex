Let $c_{i, j}$ be the number of edges. Let $M_{i, j}$ be $-c_{i, j}$ if $i \neq j$, and $\mathrm{deg} i$ otherwise.
Then the number of spanning trees of the graph is the any cofactor of $M$.

For directed spanning tree, $c_{i, j} = (i \rightarrow j)$ and $c_{i, i} = \mathrm{indeg} i$.
The number of spanning trees are the cofactor of $(r, r)$.
